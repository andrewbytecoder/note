


## 不支持命令行的容器中执行
### 统计进程名
```bash
for pid in $(ls /proc | grep -E '^[0-9]+$'); do
  echo "PID: $pid, Name: $(cat /proc/$pid/comm), Cmd: $(tr '\0' ' ' < /proc/$pid/cmdline)"
done
```

输出如下：
```bash
PID: 11, Name: nginx, Cmd: nginx: master process /usr/sbin/nginx -e stderr 
PID: 124, Name: nginx, Cmd: nginx: worker process 
```



## 根据文件内容再执行操作

### 查找包含指定内容的文件，然后执行操作
```bash
grep -ril "r-il33436642d7ad54.redis.rds.ops.zhw-bj.cloud:6379" . | xargs -I {} kubectl apply -f {}
```
 
 `grep -ril "r-il33436642d7ad54.redis.rds.ops.zhw-bj.cloud:6379"` 包含内容的文件列表
 `xargs -I {} kubectl apply -f {}` 将上述输出的内容 挨个执行 `kubectl apply -f {}`
