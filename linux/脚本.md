


## 不支持命令行的容器中执行
### 统计进程名
```bash
for pid in $(ls /proc | grep -E '^[0-9]+$'); do
  echo "PID: $pid, Name: $(cat /proc/$pid/comm), Cmd: $(tr '\0' ' ' < /proc/$pid/cmdline)"
done
```

输出如下：
```bash
PID: 11, Name: nginx, Cmd: nginx: master process /usr/sbin/nginx -e stderr 
PID: 124, Name: nginx, Cmd: nginx: worker process 
```
