





## `kubectl-trace`

`kubectl trace` 是一个 kubectl 插件，允许您在 Kubernetes 集群中执行 [bpftrace](https://github.com/iovisor/bpftrace) 程序 

**追踪具体函数的执行结果**
如果需要追踪某个执行的结果，可以使用如下命令
```bash
kubectl trace run -e 'uretprobe:/proc/$container_pid/exe:"main.counterValue" { printf("%d\n", retval) }' pod/caturday-566d99889-8glv9 -a -n caturday
```


## `kubectl-netshoot`

1. 将 `kubectl-netshoot` 复制到 `/usr/local/bin` 目录下
    
2. 下载 `nicolaka/netshoot` 镜像并上传到本地镜像仓库
    
3. 执行以下命令使用neshoot
    

运行一个临时netshoot容器

```bash
kubectl netshoot run tmp-shell2 --image-name=harbor.com/nicolaka/netshoot
```

使用netshoot挂载到一个容器上

```bash
kubectl netshoot debug dp-proxy-7db4df9fd8-zldjk --image-name=harbor.com/nicolaka/netshoot  -- sh
```
